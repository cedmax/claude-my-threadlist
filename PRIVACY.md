# Privacy policy

_Last updated: 5 November 2026_

playlist-creator creates and manages playlists on its own dedicated YouTube channel, using the YouTube Data API.

## What it accesses

- The YouTube channel it is authorised on, to create playlists and add videos to them.
- Public YouTube video IDs supplied to it.

## What it collects and stores

It collects no personal data from anyone. The only thing it keeps is the OAuth refresh token for its own channel, stored as a private secret and used solely to call the YouTube Data API.

## Sharing

No data is sold, shared or transferred to third parties.

## Google API services

playlist-creator's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time from the Google account's [third-party connections](https://myaccount.google.com/connections) page.
